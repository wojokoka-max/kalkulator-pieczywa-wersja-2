# Kalkulator pieczywa

Prosty kalkulator pieczywa na zakwasie i zaczynach drożdżowych.

Obejmuje:
- chleby pszenne i pszenno-żytnie,
- chleby z większym udziałem żyta,
- bułki,
- chałki,
- rogale,
- croissanty,
- cynamonki,
- focaccię i pizzę,
- zakwas 100%,
- sztywny zakwas,
- bigę,
- poolish.

Wyniki są punktem startowym. Fermentacja zależy od mąki, siły zakwasu, temperatury i sposobu wyrabiania.
